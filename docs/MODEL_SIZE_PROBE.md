# Habitat 相机和 Qwen3-VL 的选型记录

当前配置固定为 **960×540、Qwen3-VL-2B-Instruct 4-bit**。这个尺寸能比 480×270 显示更多物体细节，推理负担也在本机可接受范围内。M4 实测数值如下，Windows RTX 3060 6 GB、4060 8 GB 尚待实机验收。

## 同一机位提高相机分辨率

在同一套 HM3D 住宅，分别用一组带线索四图和一组衣帽间四图询问同样的三道 OpenEQA 原题。两种模型和三个分辨率共用机位、题目和提示词。正确数只计带线索的三题，耗时取每种配置六次推理的中位数，内存为 MLX 进程报告的峰值。

| 每张输入图 | 2B 答中 | 4B 答中 | 2B / 4B 中位耗时 | 2B / 4B MLX 峰值 |
|---|---:|---:|---:|---:|
| 480×270 | 1/3 | 0/3 | 1.42 / 2.57 秒 | 2.58 / 3.90 GB |
| 960×540 | 0/3 | 0/3 | 5.60 / 10.18 秒 | 2.80 / 4.08 GB |
| 1920×1080 | 0/3 | 0/3 | 45.76 / 86.32 秒 | 3.83 / 5.25 GB |

三档里，两个模型都将沙发答成 L 形（官方 C 形），对毛巾架用途都答 unknown。餐厨题仅 2B 在 270p 答对。三道题尚不足以排除分辨率对其他题型的影响。所有衣帽间对照均答 unknown。

Habitat 能设置相机宽高；组内开发渲染脚本固定 16:9，高度可取 9 的正整数倍，例如 360、540、720、900、1080。团队统一使用 540p。Mac 与 Windows 都采用 2B，分别记录 MLX 和 CUDA NF4 后端以供比较。

原始逐题对照与旧复现命令保存在 [Git 历史版本](https://github.com/Charlie0768/c6-active-eqa/tree/d4b1dc5)。本轮已清理测试图片、压缩包和本地 4B 权重。
