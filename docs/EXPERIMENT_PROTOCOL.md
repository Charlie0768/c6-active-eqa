# 实验协议草案

状态：**未冻结，不可直接视为正式实验配置**。用于防止实现过程改变比较含义。所有待定项在开发集上确定，并在运行测试前记入 DECISIONS。

## 研究与条件

- 主要问题：问题引导相比随机探索是否改善回答准确率／动作成本？
- 增量问题：轻量语义记忆是否减少重复搜索和提前停止错误？
- B0：初始视角；B1：随机；B2：引导；B3：引导 + 记忆。
- 消融候选：B3 早停 vs. 强制继续。仅在资源允许时开展。

## 数据设计

按住宅划分 OpenEQA HM3D 官方题，保留 question_id、episode_history、原题和评分专用的参考答案。登记实际可访问场景、起点选择规则、抽样种子和题型分布。先冻结测试清单，再运行测试组。

## 输入隔离

允许候选：问题、RGB、动作历史、步数、动作反馈、预声明自身位姿。
禁止：完整 metadata、目标全局位置、未观察物体、正确答案、评分标签、参考轨迹。
诊断渲染、俯视全场景图、分割掩码仅供离线评分／回放，除非另开并披露使用额外传感器的实验。

## 公平性与预算（待实现后冻结）

- 主动条件最多 20 次环境动作。成功与失败环境动作均计数。
- 建议 invalid action 消耗一个决策机会／预算槽位，或采取另一种有上限规则；必须明确，不能无限免费修复。
- `ANSWER` 为终止信号，不计移动动作；第 20 次动作后的终帧仍可用于一次最终回答。
- 回答前最多 21 个观察位置，步数从初始帧 0 开始；不能免费先旋转一圈获取全景。
- B1 固定随机分布与行动集合，不使用目标信息避障或过滤目标；普通执行反馈可按共同规则处理。
- B2 与 B3 除结构化记忆外保持提示、停止标准、图像可见范围、行动集合一致。
- 所有探索条件最终回答采用相同模型和预先规定的帧选择方案，例如相同最大帧数及采样规则。B3 额外语义记忆是被测因素，额外 token 必须统计。
- 如使用模型生成逐帧观察供记忆整理，明确哪些条件也获得该观察，控制额外调用，不能把更大计算预算全部解释为地图收益。
- 参数（步长、旋转／俯仰角度、图像尺寸、模型生成参数、历史长度、种子）填入配置后冻结。

## 指标与评分

- 按官方参考答案计算 OpenEQA LLM-Match，记录评审模型、提示、版本、评分尺度和人工抽查。更换评审模型需单独标注。
- 同时报动作数、证据支持率、调用次数、token 和耗时；按题型与场景报告。人工正确率注明样本及分母。
- 重复实验做配对分析；按场景重采样表达不确定性，说明小样本限制。

## 停止与失败分析

- 初版使用启发式证据停止：具体条件、阈值和是否要求重复确认待开发集确定。
- 不把模型自报 confidence 当校准概率，不宣称共形预测保障。
- 证据层标签：证据不足、证据已充分但答错、证据充分性不明确。
- 停止层标签：过早停止、耗尽预算、其他。与证据层可交叉，不强行互斥。
- 过早停止需有参考取证路径／延续轨迹和人工复核支撑，不能只因答案错误就标记。
- 工程错误独立记录，不能静默移除；方法归因不确定时保留 unknown。

## 版本、日志与数据保留

每次 run 记录代码提交、协议版本、模型版本、数据／配置哈希、种子、日期、运行环境。
每个 episode 记录题目 ID、起始状态、每帧路径、模型输入输出、动作、反馈、答案、评分、token、延迟、错误／重试、停止原因。
图像和原始输出在忽略目录保存，维护小型哈希清单及备份位置；测试真值不可混入模型请求缓存。
记录失败与部分运行，缺失项补齐之前不发布完整汇总。离线重新评分不得再次向模型暴露真值。
