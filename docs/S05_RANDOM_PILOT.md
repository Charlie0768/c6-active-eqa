# B1 随机探索两题 pilot

日期：2026-11-17。状态：**运行管线试验，不是冻结的正式 B1 对照实验**。

用户已确认“厨房的房门是否白色”这道开发题的目标和棕色房门证据；`data/dev_labels.json` 已将第二题更新为用户复核。此前 B0 两题仅看初始画面，按确认真值得 1/2。

## 策略与输入边界

[`run_b1_random.py`](../scripts/run_b1_random.py) 对每题重置 `FloorPlan1`，用 `seed=17` 从 `RotateRight`、`RotateLeft`、`MoveAhead`、`LookUp`、`LookDown` 中等概率抽取 **20 次**动作。同一随机种子在两题产生完全相同的动作序列；策略不根据题目、场景物体清单、真值或动作成功与否改变下一动作。执行前扣预算，失败动作也计数。

每题保存起点及 20 次行动后的全部 21 张 RGB 帧，供回放与审计。为限制模型输入，本 pilot 事先固定只抽取时间步 `0、7、13、20` 这 4 帧；抽取规则只看时间索引，不看图像内容。模型只收到题目和这 4 张选中帧，**没有收到其余 17 张帧、完整仿真 metadata、答案或参考路径**。全部轨迹只写在本地日志里。正式 B1/B2/B3 的共同帧选择规则尚未冻结。

本机复现（输出目录必须是新目录）：

```bash
HF_HOME=.cache/huggingface HF_HUB_OFFLINE=1 HF_HUB_DISABLE_IMPLICIT_TOKEN=1 \
  ./.venv-vl/bin/python scripts/run_b1_random.py \
  --seed 17 --budget 20 --output runs/s05-b1-new
./.venv-vl/bin/python scripts/score_answers.py \
  --predictions runs/s05-b1-new/predictions.json \
  --output runs/s05-b1-new/scores.json
```

## 实际结果与关键限制

最终原始结果在本机被 Git 忽略的 `runs/s05-b1-seed17-pilot/`。两题各 20 次动作，其中各 16 次成功、4 次失败；42 张 PNG 均可打开，文件哈希与预测记录一致。模型对冰箱题答“是”，对房门白色题答“否”，JSON 格式均有效。离线评分是 **2/2，平均行动数 20，自定义效率分均值 0.5**。在同两题的 B0 pilot 中，分数是 **1/2，平均行动数 0，效率分均值 0.5**。例如 B1 每题答对但走满 20 步，单题效率是 `1 - 20/40 = 0.5`。

**不能把 B1 第二题的答对归功于看见房门。**人工检查完整轨迹发现深棕色房门出现在 [第 10 步画面](figures/door-step10.png)，但模型实际收到的是第 0、7、13、20 步；[这 4 帧的拼图](figures/door-selected.png)没有清楚显示房门。模型仍答“否”，具体原因不可由这次记录判定。**答案正确**与**证据充分**必须分别检查；不能用正确率反推探索已获得证据。

本机 MLX 对两次四图生成报告的峰值约为 2.518/2.519 GB；每题计时约 2.373/1.270 秒（从该题重置到生成结束，不含一次性 Unity/模型加载）。两题顺序运行只说明这个 pilot 可运行，仍不能证明连续 10 题或更大帧历史在 16 GB 统一内存上稳定。付费调用为 0。
